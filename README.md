# STAP – AI-Powered Recruitment Platform

> **Hire smarter. Build better teams.**  
> An intelligent recruitment platform that coordinates specialized AI agents to automate sourcing, screening, interviews, and hiring decisions.

---

## 🌟 What is STAP?

**STAP** is an all-in-one hiring platform built for modern companies. Instead of spending hours reading through hundreds of resumes, sending back-and-forth scheduling emails, or doing manual evaluations, STAP uses **six specialized AI agents** to handle the heavy lifting while recruiters make the final decisions.

Whether you are a startup hiring your first engineer or an enterprise scaling your team, STAP makes recruitment fast, fair, and effortless.

---

## 🚀 Key Features

- **🤖 6 Specialized AI Agents**
  - **Sourcing Agent:** Finds and structures candidate profiles from across the web.
  - **Screening Agent:** Matches resumes with job requirements in seconds.
  - **Interview Agent:** Runs structured, adaptive video/voice AI interviews.
  - **Evaluation Agent:** Automatically scores answers and creates clear scorecards.
  - **Scheduling Agent:** Coordinates calendars and books interviews with zero hassle.
  - **Compliance Agent:** Ensures unbiased, fair, and legally compliant hiring.

- **📊 Command Center Dashboard**
  - Real-time pipeline tracking (Applied → Screening → Interview → Evaluation → Offer).
  - Live AI agent activity monitor.
  - Top candidate scoring and rank overview.

- **⚡ Interactive & Accessible Web Experience**
  - **Smooth Scrolling Navigation:** Fast jumps with back-button history support and keyboard accessibility.
  - **Interactive Modals:** Built-in "Book a Demo", "Talk to Sales", and "Log in" forms with inline validation.
  - **Theme Toggle:** Switch smoothly between **Light Mode** (warm cream) and **Dark Mode** (sleek obsidian).
  - **Mobile Friendly:** Fully responsive with an accessible hamburger drawer menu.
  - **Back to Top Button & Scroll Progress Bar:** Clean UX indicators that respect user motion preferences.

- **💰 Transparent Pricing Tiers**
  - **Starter ($499/mo):** For early teams making 1–3 critical hires.
  - **Growth ($1,299/mo):** All 6 AI agents with unlimited sourcing and ATS integrations.
  - **Enterprise (Custom):** Tailored AI rubrics, dedicated support, and enterprise compliance.

## 💻 How to Run This Project Locally

You don't need any complex installation or heavy software. Here are two easy ways to run it:

### Option 1: Direct in Browser (Simplest)
Just double-click on **`index.html`** or right-click and choose **Open with > Google Chrome** (or Edge, Safari, Firefox).

---

### Option 2: Run with Local Server (Recommended)
Running with the included local server enables API mock responses for the Demo, Sales, and Login forms.

1. **Open your terminal or command prompt** in the project folder.
2. **Run the server:**
   ```bash
   python server.py
   ```
3. **Open your browser and visit:**
   ```
   http://localhost:3000
   ```
